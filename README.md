# Random Defect Generator

This project is a Python application that generates and visualizes random visual defects.  
It focuses on three defect types: air bubbles, scratches, and dirt stains, using image-processing and geometric calculations.

## Features

- Generate random defect types:
  - Air bubbles
  - Scratches
  - Dirt stains

- Calculate defect-related properties:
  - Ellipse axis ratio
  - Amount of defect material inside the ellipse

- Visualize generated defects using Matplotlib
- Use OpenCV and SciPy for image processing and shape generation
- Interactive defect selection through console input

## Requirements

- Python 3.9 or higher
- NumPy
- OpenCV
- Matplotlib
- SciPy

## Setup and Installation

Clone the repository:

```bash
git clone https://github.com/SharonMelanker/random-defect-generator.git
cd random-defect-generator
```

Install dependencies:

```bash
pip install numpy opencv-python matplotlib scipy
```

Run the project:

```bash
python Function1.py
```
